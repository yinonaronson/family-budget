# הכיס המשפחתי — אפליקציית אייפון/אנדרואיד

מעטפת Expo סביב האתר https://thefamilypocket.com, עם תוספות של טלפון:

- **נעילה בזיהוי פנים / טביעת אצבע** — בפתיחה, ושוב אחרי דקה ברקע.
- **תזכורת יומית** לרשום הוצאות (התראה מקומית, בלי שרת).
- **שיתוף** — `navigator.share` של האתר נפתח בגיליון השיתוף של הטלפון.
- **ייצוא קבצים** — `dl()` של האתר שולח את הקובץ לאפליקציה, שמשתפת אותו.
- **קישורים חיצוניים** (אינסטגרם, מייל, וואטסאפ) נפתחים מחוץ לאפליקציה.
- **מסך "אין חיבור"** עם ניסיון חוזר.

האתר מזהה שהוא בתוך האפליקציה לפי `window.ReactNativeWebView`, ומוסיף בהגדרות כרטיס "הגדרות האפליקציה".

## פיתוח
```
npm install
npx tsc --noEmit
npx jest
```
